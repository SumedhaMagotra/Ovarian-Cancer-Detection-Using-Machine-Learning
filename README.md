The project proposes a machine learning approach to improve ovarian cancer detection using an ensemble deep learning model 
combining VGG16 and InceptionV3 architectures. To address limited data, we augmented the STRAMPN dataset with synthetic images 
generated by GANs, enhancing model generalization. The ensemble achieved a high classification accuracy of **98.8%**, 
outperforming other pre-made models in precision, recall, and F1-score. 
The project highlights the potential of this method to improve clinical sensitivity and survival rates. 
Future work may explore real-time clinical applications and integration with multimodal medical data for deeper diagnostic insights.
